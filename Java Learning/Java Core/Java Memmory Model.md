
Модель памяти задана с точки зрения действий, которые включают чтение и запись с переменных, блокировку и присоиденение потоков. JMM устанавливает понятие happens-before для всех действий в програме, что значит что бы поток выполняющий действие В должен видеть все изменения которые сдлела поток А, между ними должно быть отношение happens before. **Гонка даних происходит когда переменная считывается более чем одним потоком  и пишется по крайней мере одним потоком, но операции чтения и записи не ограничены отношщением happens-before**.
Правила для упорядочивания "происходит перед":
1. Правило програмного порядка - каждое действие в потоке происходит перед каждым действием которое находитсся дальше в програмном коде
2. Праивло мониторного замка - каждый unllock монитора происходит перед операцие лок на то м же мониторе
3. Правило волатильной переменной - запись в волатильную переменную происходит перед каждым чтением с этого же поля
## Платформенные модели памяти
В многопроцессорной среде каждый процессор имеет сообственный кеш который время от времени согласовывается с общей памятью. Модель памяти описыват какие гарантии можно ожидать от системы памяти и оглашает набор инструкций, которые нужны для совместного использования памяти.
