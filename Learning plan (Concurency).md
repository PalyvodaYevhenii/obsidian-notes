### 4. Архитектура и масштабируемость: Глава 10 («Предотвращение сбоев жизнеспособности») и Глава 11 («Производительность и масштабирование»)

#### 🧪 Практический тест

1. **Задача на предотвращение Deadlock при переводе средств:** Дана функция перевода денег между банковскими счетами:
    
    ```

                from.debit(amount);
                [подозрительная ссылка удалена](amount);
            }
        }
    }
    ```
    
    _Вопрос:_ Объясните, как динамический порядок аргументов вызова `transferMoney(accA, accB, 100)` и `transferMoney(accB, accA, 50)` из разных потоков приводит к взаимной блокировке. Опишите два способа исправления: с помощью условного упорядочивания по `System.identityHashCode` (или уникальному ID) и с помощью `tryLock` с бюджетом времени.
    
2. **Задача на сужение области блокировки и открытые вызовы:** _Вопрос:_ Что такое «открытые вызовы» (_open calls_) и почему вызов внешних методов с удержанием замка считается опасным?         private static Resource resource;
    ```
        public static Resource getInstance() {
            if (resource == null) {

                        resource = new Resource();

    }
    ```
